# AI ファイルマネージャー

## 概要

AI ファイルマネージャーは、Gemini API を活用したスマートなファイル管理アプリケーションです。ファイルのテキスト要約、AIチャットアシスタント、インテリジェントな検索、ファイル操作（アップロード、ダウンロード、フォルダ作成、削除）、多言語対応（英語/日本語）などの機能を提供し、ユーザーがファイルをより効率的に整理、検索、理解できるように支援します。

## 前提条件

*   Node.js (推奨バージョン: 18.x 以上)
*   npm または yarn

## APIキーの設定

このアプリケーションは Google Gemini API を使用します。APIキーを取得し、プロジェクトのルートディレクトリに `.env` ファイルを作成して、以下のように設定してください。

```env
API_KEY=YOUR_GEMINI_API_KEY
```

**注意:** `YOUR_GEMINI_API_KEY` は実際のAPIキーに置き換えてください。この `.env` ファイルはGitの追跡対象から除外することを推奨します（`.gitignore` に `.env` を追加してください）。

アプリケーションは `vite.config.ts` の設定を通じて、`process.env.API_KEY` としてこのAPIキーをフロントエンドコードから利用します。

## 開発環境

このプロジェクトは `Vite` を使用して開発環境を構築・実行します。

*   **`package.json`**: プロジェクトの依存関係（React, TypeScript, @google/genaiなど）とスクリプト（`dev`, `build`, `preview`）を定義しています。
*   **`vite.config.ts`**: Vite の設定ファイルです。Reactプラグインの有効化や、`.env` ファイルから `API_KEY` を読み込み、アプリケーションコード (`process.env.API_KEY`) で利用可能にする設定が含まれています。
*   **`index.html`**: アプリケーションのエントリーポイントです。
*   **`index.tsx`**: ReactアプリケーションをマウントするメインのTypeScriptファイルです。

## インストール

1.  プロジェクトのルートディレクトリに移動します。
2.  依存関係をインストールします。

    ```bash
    npm install
    # または
    yarn install
    ```

## 開発サーバーの起動

アプリケーションをローカルで起動するには、以下のコマンドを実行します。

```bash
npm run dev
# または
yarn dev
```

これにより、Vite開発サーバーが起動し、ターミナルに表示されるローカルアドレス（例: `http://localhost:5173`）でアプリケーションにアクセスできるようになります。`.env` ファイルに記述された `API_KEY` がアプリケーションに提供されます。

## 主な機能

*   ファイルとフォルダの表示・ナビゲーション
*   ファイルアップロード（ドラッグ＆ドロップ対応、フォルダアップロード対応）
*   フォルダ作成
*   ファイル削除（フォルダの場合は内容も含む）
*   ファイルダウンロード
*   AIによるテキストファイル（.txt, .md, .pdf, .docx）の要約
*   ファイル名、更新日、ファイルタイプ、ファイルサイズによるフィルタリングおよび検索
*   AIチャットアシスタント (現在のファイルコンテキストに基づいた応答)
*   音声入力による検索およびAIチャット (ブラウザが対応している場合)
*   多言語対応（英語、日本語）切り替え機能

## 注意事項
* このアプリケーションはデモ目的であり、実際のユーザー認証や永続的なファイルストレージは実装されていません。データはブラウザのセッション中のみ保持されます。
* Gemini APIの利用には、利用規約の遵守と、適切なAPIキー管理が必要です。
* `index.html`には`importmap`の記述がありますが、Viteによる開発では主に`package.json`の依存関係が利用されます。
